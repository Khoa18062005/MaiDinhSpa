# Hướng dẫn Thư mục `src/asset/logo/`

Bạn hãy kéo thả file Logo chính thức của **Mai Đinh Spa** (định dạng `.png`, `.svg`, `.webp` hoặc `.jpg`) vào thư mục này nhé!

Sau khi bạn bỏ file logo vào đây, nhắn mình một câu là mình sẽ tự động gắn logo thật đó lên:
1. Thanh điều hướng đầu trang (`Navbar.tsx`)
2. Chân trang (`Footer.tsx`)
3. Cổng Quản trị Chủ Spa (`AdminSidebar.tsx`) & Trang Đăng nhập (`(auth)/layout.tsx`)
4. Biểu tượng tab trình duyệt (`favicon` / `icon`).
